# disidente.co

Landing oficial de DISIDENTE con una interfaz inspirada en una terminal.

El sitio es estático, no utiliza librerías externas y se publica mediante
GitHub Pages.

## Estructura

- `index.html`: landing principal, estilos y comportamiento interactivo.
- `favicon.ico`, `favicon.svg`, `favicon-32.png` y `apple-touch-icon.png`:
  iconos del sitio.
- `og-image.png`: imagen para las vistas previas al compartir el enlace.
- `x-logo.png`: icono del enlace a X.
- `CNAME`: dominio personalizado de GitHub Pages.
